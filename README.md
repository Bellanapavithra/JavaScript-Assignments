## Project Overview
This project contains six JavaScript assignments designed to practice fundamental JavaScript concepts. Each assignment demonstrates important programming concepts with simple code and console output.

## Assignments

### Assignment 1: Variables, Data Types, and Console Operations
- Declares variables using `var`, `let`, and `const`.
- Stores name, age, employment status, and skills.
- Uses `typeof` to identify data types.
- Displays information using `console.log()`.

### Assignment 2: Operators, Expressions, and Input Handling
- Accepts bill amount and tip percentage as input.
- Converts input strings into numbers using `Number()`.
- Calculates the tip and total bill.
- Demonstrates arithmetic and assignment operators.

### Assignment 3: Conditional Logic Implementation
- Uses `if...else` statements to determine a grade.
- Uses a `switch` statement to evaluate the grade.
- Uses a ternary operator to determine pass or fail status.

### Assignment 4: Loop Control Structures
- Uses a `for` loop to display the multiplication table of 5.
- Uses a `while` loop and `break` to find the first number greater than 10 divisible by 6.
- Uses a `do...while` loop and `continue` to skip even numbers.

### Assignment 5: Function Architecture and Scope
- Defines a standard function and an arrow function.
- Uses parameters and default values to calculate rectangle areas.
- Demonstrates block scope using `let`.
- Handles a `ReferenceError` when accessing a block-scoped variable outside its block.

### Assignment 6: Arrays, Objects, and Core Methods
- Creates an array of product objects.
- Uses `forEach()` to display products.
- Uses `filter()` to find products priced below $50.
- Uses `map()` to create formatted product descriptions.

## How to Run the Programs
1. Install Node.js from https://nodejs.org/.
2. Open the project folder in Visual Studio Code.
3. Open the terminal using **Terminal → New Terminal**.
4. Run an assignment using the following command:

```bash
node assignment1.js
```

5. Replace `assignment1.js` with the required assignment filename to execute another program.
6. For Assignment 2, enter the bill amount and tip percentage when prompted in the terminal.
